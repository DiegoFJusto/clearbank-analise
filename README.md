# Análise Financeira ClearBank 🏦

Projeto de conclusão do módulo de Python para Análise de Dados. Este notebook automatiza a leitura, validação e agrupamento de transações financeiras.

## 👨‍💻 Autor
DIEGO DE FREITAS JUSTO

## 🛠️ Tecnologias Utilizadas
- **Python 3**
- Bibliotecas Nativas: `csv`, `json`, `datetime`
- Bibliotecas Externas (Bônus): `pandas`, `matplotlib`

## 🚀 Como Executar
1. Clone este repositório ou baixe o arquivo `desafio-final.ipynb`.
2. Abra o arquivo no **Google Colab** ou **Jupyter Notebook**.
3. Execute todas as células sequencialmente (`Run All`). A primeira célula criará a base de dados (`transacoes.csv`) automaticamente para os testes.

## 📦 Saídas Geradas
Ao executar o notebook, o código irá gerar:
- Resumo visual no terminal contendo os cálculos mensais e transações suspeitas.
- Arquivo `relatorio.json` exportado com os dados consolidados.
- Arquivo `grafico.png` (Requisito Opcional) com o demonstrativo do saldo mensal.
